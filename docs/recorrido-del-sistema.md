Recorrido funcional del sistema
1. Ingreso al sistema
El usuario inicia en index.html, donde puede consultar la presentación de Red Solidaria Animal, el resumen de atención y los accesos principales.

2. Registro de un rescate
Desde el menú se accede a reportar.html. En esta página se completan los datos del animal, la categoría, el nivel de urgencia, la ubicación y la descripción del caso.

3. Consulta de casos
La página rescates.html presenta los rescates registrados en una tabla. La información permite revisar el código, la categoría, la prioridad, el sector y el estado actual.

4. Seguimiento
El estado de cada caso permite conocer si el reporte está pendiente, en atención, en recuperación o finalizado.

5. Navegación
El menú común permite regresar al inicio o desplazarse entre el formulario y el listado de rescates.
